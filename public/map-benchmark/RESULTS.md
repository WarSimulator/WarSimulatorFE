# MapLibre 지역·로컬 지도 테스트 결과

측정일: 2026-10-13. 빌드된 앱의 in-app Browser에서 측정했다.

## 판단

로컬 지도는 로딩 시간과 외부망 의존성을 줄이는 데 적합하다. 같은 지역 제한 조건에서 원격 대비 로딩은 4.60초 → 1.56초로 약 66% 감소했다. 재생 렌더 FPS 차이는 약 +0.8%였으며, 지역 제한만으로 렉이 크게 줄어드는 효과는 관찰되지 않았다. 고도 최대 줌을 z12 → z10으로 낮춘 결과도 약 +3.2%로 작았다.

따라서 로컬·지역 제한 제공은 오프라인 운영과 로딩 안정성을 위한 선택으로 권장한다. 현재 테스트에서는 고도 z12를 유지하는 것이 합리적이다. 렉 해소는 지형 렌더링, 유닛·효과의 GeoJSON 갱신, GPU 부하를 별도로 측정·최적화해야 한다. 이번 실험으로 어느 항목이 주 병목인지 확정하지는 않았다.

이번 데이터는 철원 주변 약 50km의 소규모 검증용이다. **한반도 전체 데이터의 용량·준비 시간과 실제 사용자 장비의 성능은 아직 검증하지 않았다.** 지역 전체가 아니라 화면에 보이는 타일 중심으로 렌더링하므로, 제공 범위를 줄이는 것과 화면 내 렌더 부하를 줄이는 것은 구분해서 판단해야 한다.

## 측정 조건

- `npm run build -- --outDir dist/map-benchmark-final`로 타입 검사와 production 빌드 통과 후 Vite preview에서 실행.
- 지도 canvas 1626 × 503px. 결과 표의 높이를 고정해 조건별 지도 크기가 바뀌지 않도록 했다.
- 중심 127.44°E, 38.44°N / 줌 12 / pitch 60° / bearing -12° 기준 ±10° 회전 경로.
- 모든 조건에서 같은 Protomaps 벡터 배경, terrain exaggeration 1.2, 맑음·낮 환경.
- 같은 VER1 시뮬레이션: 22개 유닛, 22개 트랙, 29개 효과. 준비된 경로를 재생하며 런타임 경로 API 요청 없음.
- 타일 준비 후 3초간 카메라 경로를 미리 재생하고 경로 타일 준비를 기다린 뒤, 10초 동안 전체 시뮬레이션 시간대를 재생하며 측정.
- 조건별 2회. 2회차는 순서를 반전. 8회 모두 완료, 기록된 타일 오류 0건.
- FPS는 지도 `render` 이벤트의 간격 기준이며 GPU 실행 시간 측정이 아니다. p95는 프레임 간격의 95백분위수.
- 브라우저·OS 캐시는 초기화하지 않았다. 로딩 시간은 캐시와 네트워크 영향을 받으며, 최초 설치/완전한 cold start 시간으로 해석하지 않는다. 원격 배경 지도는 같은 서버의 고정 upstream Range 중계를 거친다.

## 데이터와 한계

배경 316타일 / 3.87MiB, 고도 106타일 / 12.66MiB. 로컬 지도·지도 글꼴·시뮬레이션 데이터는 앱에서 제공한다. 실제로 외부망을 끊은 브라우저 재생 검증은 실시하지 않았으며, 앱 공통 Google Fonts는 네트워크 없이 시스템 글꼴로 대체된다.

모든 조건에 동일한 벡터 배경을 사용했다. 기존 MapLibre 데모의 OSM 이미지 배경과는 다르므로 기존 데모에 대한 절대 FPS 향상 수치로 사용할 수 없다. 지형과 유닛·전술 도형이 함께 표시되는 화면은 확인했지만 z10/z12의 능선 품질을 정밀하게 비교한 결과는 아니다. 눈·비 조건은 메뉴에서 추가 측정할 수 있으며 이번 최종 8회 비교는 맑음만 측정했다.

개발 중 타일 준비 미완료, 스타일 갱신 충돌, 자동 갱신으로 중단된 측정은 이 표에 포함하지 않았다. Production 초기화 중 발견한 MapLibre 6 worker 경로 문제도 수정한 뒤 최종 측정을 수행했다. worker는 [MapLibre 공식 Vite 안내](https://github.com/maplibre/maplibre-gl-js/blob/main/docs/index.md#esm)에 따라 `?worker&url`로 번들에 포함한다.

## 다시 측정하기

사이드바 **MapLibre 지역·로컬 성능 테스트** → 날씨·반복 횟수 선택 → **전체 비교 시작**. 동일한 화면 크기를 유지하고 테스트 중 다른 탭으로 전환하지 않는다. **결과 JSON 저장**으로 카메라·canvas 크기와 정밀 수치, 오류 및 무효 사유를 저장할 수 있다. 원격 비교에는 `npm run dev` 또는 `npm run preview` 서버와 인터넷이 필요하다.

검증: benchmark 통계·무효 제외·타일 범위·로컬 폰트·Range 중계 검사, 날씨 렌더링 성능 회귀 검사, 날씨 상태 및 Revision deployment 회귀 검사, `git diff --check` 통과.

## 실제 MapLibreGL 시뮬레이터 적용 검증

실제 `/simulations/3d-demo-maplibre` 실행 경로에 로컬 지도와 작전 경계를 적용했다. 재생과 Revision이 같은 패키지 및 경계를 사용하며 고도 z12를 유지한다. 다른 지도 모드 및 별도 ver0 편집기의 지도 선택은 변경하지 않았다.

Production 미리보기에서 제공된 VER1 세트를 불러와 실제 시뮬레이션을 생성하고, 로컬 3D 지형과 유닛·전술 도형 표시, 타임라인 재생, 약 5.65초에서 정지 후 Revision 진입, 유닛 명칭 편집·복구, 눈 입자 및 적설, 비 환경 전환을 확인했다. 이 확인은 기능 검증이며 실제 데모의 적용 전후 FPS 재측정은 아니다.

`test-local-operation-map.mjs`는 지역 밖 유닛·목표·LineString·Polygon, 저장된 경로·효과, 비유한 좌표를 검사한다. 지역 밖 입력은 도로 요청 전에 거부하고, 시작·끝 좌표가 안에 있어도 도로가 중간에 지역 밖으로 우회하면 전체 경로를 거부한다. 다른 지도 모드에서 해당 경로 제한이 활성화되지 않는 것도 검사했다. 타일·통계·날씨·Revision 검사와 타입 검사 및 빌드는 통과했다.

기존 `test-force-plan.mjs`는 파서의 `destination: northern-flank` 반환에 대해 빈 parameters 객체를 기대하는 단언문(33행)에서 실패했다. 원래 검사 파일을 그대로 실행해도 같은 실패가 재현되며, 이번 지역 지도 변경에서는 해당 파서나 검사의 기대값을 변경하지 않았다.
